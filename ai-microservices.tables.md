# A more useful roadmap view

The **145 services** above shouldn't be treated as 145 separate projects. Many share the same underlying infrastructure.

I'd organize the implementation into layers:

| Layer                     | What you build                       | Enables                        |
| ------------------------- | ------------------------------------ | ------------------------------ |
| **1. Foundation**         | LLM gateway, authentication, logging | Everything                     |
| **2. Document layer**     | PDF/DOCX parsing, OCR, chunking      | Writing, thesis, papers        |
| **3. RAG layer**          | Embeddings, vector search, citations | Literature, policies, courses  |
| **4. Verification layer** | DOI/Crossref/OpenAlex/API checks     | Reference/citation services    |
| **5. Academic reasoning** | Specialized prompts/models           | Reviewers, methodology, thesis |
| **6. Evaluation**         | Test datasets + benchmarks           | Trustworthy deployment         |
| **7. UI/API layer**       | Small endpoints + web interfaces     | Actual user services           |

The important realization is that **service #11, #12, #13, #19, #66 and #135 may all use much of the same underlying infrastructure**.

## My recommended first wave

If the goal is to demonstrate that your platform can become a **real university AI service layer**, I'd make the first 10:

1. ✅ **Proofreader**
2. ✅ **Coder**
3. ✅ **Translator**
4. ⬜ **Reference Checker**
5. ⬜ **Citation–Claim Checker**
6. ⬜ **Academic Linter**
7. ⬜ **Paper Pre-Reviewer**
8. ⬜ **Research Preflight**
9. ⬜ **Thesis Auditor**
10. ⬜ **Literature Screening Assistant**

That gives you a very compelling portfolio because it demonstrates **generation, transformation, retrieval, verification, reasoning, and evaluation** rather than simply having ten different chatbots.

And the really nice part is that **#4–#8 can share a common "academic verification engine."** That gives you a technically coherent project rather than a random collection of LLM demos.
